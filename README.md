# Portal Educacional Tech Senai Botucatu 🚀

Bem-vindo ao repositório oficial do **Portal Educacional Tech Senai Botucatu**, uma plataforma web desenvolvida para apresentar o Curso Técnico em Desenvolvimento de Sistemas, destacar seus diferenciais, prover canais de contato e gerenciar inscrições de novos estudantes.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da web, com foco em boas práticas, semântica e acessibilidade:

*   **HTML5 Semântico:** Utilização correta de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<fieldset>` e `<legend>` para otimização de SEO e acessibilidade para leitores de tela.
*   **CSS3:** Estilização moderna utilizando Flexbox, Grid Layout, seletores avançados, efeitos de transição e responsividade.

---

## 📂 Estrutura do Projeto

O projeto é composto por páginas independentes integradas por um menu de navegação comum:

1.  **`index.html` / `semantica.html`:** Página principal contendo o formulário de inscrição avançado focado na escolha de turnos e captação de dados dos alunos.
2.  **`cursos.html`:** Seção detalhada apresentando os principais módulos do curso (Desenvolvimento Web Full Stack, Aplicativos Mobile, Back-end & APIs Seguras e Automação).
3.  **`sobre.html`:** Apresentação institucional com os objetivos de aprendizado, diferenciais e metas do curso técnico.
4.  **`contato.html`:** Página com formulário de contato e links diretos para as redes sociais oficiais e canais de atendimento (WhatsApp, Instagram, Facebook, LinkedIn e Ouvidoria).

---

## 🚀 Como Executar o Projeto Localmente

Para testar e rodar o projeto diretamente no seu computador, siga os passos abaixo:

1.  **Clone este repositório:**
    ```bash
    git clone https://github.com/seu-usuario/nome-do-repositorio.git
    ```
2.  **Abra a pasta do projeto** em seu editor de código favorito (como o *Visual Studio Code*).
3.  **Abra o arquivo principal** (`semantica.html` ou `index.html`) em seu navegador web (clique duas vezes no arquivo ou utilize a extensão *Live Server* do VS Code).
